# Requirements Specification

Specifies requirements derived from business rules for this project. They should be fulfilled,
at every cost. At this design step it does not matter how they are fulfilled, but rather how
system should behave.

## Skills

| Skill                 | Purpose                                                          |
| --------------------- | ---------------------------------------------------------------- |
| `add-requirement`     | Adds a new requirement to the matrix and exports its PDF.        |
| `requirements-to-erd` | Builds or updates the whole ERD from the requirements matrix.    |
