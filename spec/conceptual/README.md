## Skills

| Skill                    | Purpose                                                                 |
| ------------------------ | ----------------------------------------------------------------------- |
| `requirements-to-erd`    | Builds or updates the whole ERD from the requirements matrix.           |
| `erd-to-uml`             | Builds the whole UML class diagram and its constraints from ERD.        |
| `uml-to-relational`      | Builds the whole relational model and its constraints from the UML.     |
| `modify-erd`             | Makes one change in the ERD, such as renaming an entity.                |
| `modify-uml`             | Makes one change in the UML, such as adding a class or a link.          |
| `modify-relational`      | Makes one change in the relational model, such as renaming a table.     |
| `uml-constraints`        | Writes down the rules that the UML diagram cannot show.                 |
| `relational-constraints` | Writes down the rules that the relational model diagram cannot show.    |
| `requirements-coverage`  | Traces the functional and non-functional requirements to the design.    |
| `validate-erd`           | Checks the ERD notation and that it covers every requirement.           |
| `validate-uml`           | Checks that the UML matches the ERD and the requirements.               |
| `validate-relational`    | Checks that the relational model matches the UML and its constraints.   |
