# Requirements to Implementation Matrix

Drink DJ database in PostgreSQL. The scripts are in the folder Database in the root of the repository. Every bullet of Verification Needed is one test of Database/tests/run_tests.sql. C01-C42 are the constraints of relational_model_constraints.pdf.

| Requirement | Affected Structure | Planned Enforcement | Verification Needed |
